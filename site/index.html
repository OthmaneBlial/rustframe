The missing middle

A browser tab is too small.
A native backend is too much.

RustFrame sits between them: a deliberately bounded native substrate for applications whose value lives in local structured data, user-selected files, and repeatable machine workflows.

Least privilege you can explain

The frontend never gets a master key.

A person chooses a folder. RustFrame returns an opaque grant. Every read, write, watch, dialog, database call, command, and window action is authorized inside native IPC.

  • ✓ per-window permissions
  • ✓ revocable file grants
  • ✓ bounded command arguments and output
  • ✓ rate, size, timeout, and traversal limits
  • ✓ no telemetry by default

Use the prebuilt CLI for the shortest path. Rust and the host WebView toolchain are still required to compile the stock native runner.

  1. 1Install the CLI
  2. 2Run rustframe doctor
  3. 3Create and open your workflow
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/OthmaneBlial/rustframe/releases/download/v0.1.0-rc.1/rustframe-cli-installer.sh | sh
powershell -ExecutionPolicy Bypass -c "irm https://github.com/OthmaneBlial/rustframe/releases/download/v0.1.0-rc.1/rustframe-cli-installer.ps1 | iex"
cargo install rustframe-cli --version 0.1.0-rc.1 --locked
